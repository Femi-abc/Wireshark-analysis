Wireshark packet analysis report

Objective

Capture and analyze network traffic generated during web browsing activity in a Kali Linux virtual lab.

Tools used

- Kali Linux
- Wireshark
- VirtualBox

Traffic captured

- DNS queries
- TCP connections
- TLS/HTTPS traffic
- NTP traffic

Analysis

DNS

Observed domain name resolution requests between the virtual machine and DNS servers.

TCP

Observed TCP communication between the virtual machine and remote web servers, including acknowledgments and established connections.

TLS

Observed encrypted HTTPS traffic generated during web browsing sessions.

NTP

Observed network time synchronization traffic.

Skills demonstrated

- Packet capture
- Protocol analysis
- DNS analysis
- TCP traffic inspection
- Wireshark filtering
- Network traffic investigation

Conclusion

This exercise demonstrated the ability to capture, filter, and analyze network traffic using Wireshark in a controlled virtual lab environment and document findings in a professional technical report.
